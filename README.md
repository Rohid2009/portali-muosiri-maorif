# Портали муосири маориф

Журнали электронии **МТМУ №12** бо забони тоҷикӣ. **Next.js 14 · TypeScript · PostgreSQL (Prisma) · Tailwind.**

Портал барои як мактаб танзим шудааст: номи мактаб дар саҳифаи асосӣ ва сарлавҳа, сабти номи волид бе интихоби мактаб.
Сохтори база (`school_id` дар ҳар ҷадвал) боқӣ мондааст — агар баъдтар мактаби дигар илова шавад, кодро иваз кардан лозим нест.
Ҳамаи 7 қадами нақша иҷро шудааст.

## Нақшҳо ва имкониятҳо

| Нақш | Ворид | Чӣ кор мекунад |
|---|---|---|
| **Омӯзгор** | «Барои омӯзгорон» | Танҳо фан/синфҳои ба ӯ тақсимшуда → журнал: баҳо (1–10), ҳаст/нест/сабабнок, одобу рафтор. Сана худкор. Баҳоро иваз карда наметавонад → «дархости тасҳеҳ». Ҷадвали имрӯза, баҳоҳои чорякӣ, содироти журнал. |
| **Волид** | «Барои волидон» | Худаш сабти ном мекунад (ном, рақами телефон, парол), мактаб → синф → фарзандро аз рӯйхат интихоб мекунад (танҳо номи кӯтоҳ, мисли «Мадина Б.»). Дархост ба мутахассис меравад; **баъди тасдиқ** танҳо фарзанди худро мебинад: баҳоҳо, давомот, рафтор, чорякҳо. Воридшавӣ бо телефон. Танҳо хониш. |
| **Чат ва рӯйхати тамос** | омӯзгор ↔ волид | Омӯзгор рӯйхати волидонро (бо фарзанд, синф, телефон), волид рӯйхати омӯзгоронро (бо фан, синф, телефон) мебинад; ҷустуҷӯ бо пешниҳоди номҳо аз ҳарфи аввал ва филтри алифбо. Тугмаи «Навиштан» → чат (паёмҳо дар база, навсозии худкор, «хонда шуд»). Ҳар кас рақами худро пинҳон карда метавонад. **Чатбот ё ҷавоби худкор нест** — паёмро танҳо худи омӯзгор ё волид аз ҳисоби худ мефиристад (ҳимоя аз скриптҳо: майдони пинҳонии «дом», фосилаи ҳадди ақал, маҳдудияти шумора, радди паёми такрорӣ). |
| **Мутахассис** | «Мутахассис» | Сол ва чорякҳо, фанҳо, синфҳо, омӯзгорон (пароли автоматӣ), тақсими фан/синф (бисёр-ба-бисёр), хонандагон + ҳисоби волид (пароли автоматӣ, иловаи якбора), ҷадвал, дархостҳои тасҳеҳ, ҳуҷҷати «сабабнок», интиқоли омӯзгор, бастани чоряк, баҳои имтиҳон, охири сол (гузариш, бозмондагон, хориҷшудагон, таърих), танзимот, содирот. |
| **Мудир** | «Мутахассис» | Ҳисобот (давомот, баҳо, синфҳо), мутахассисонро идора мекунад, сабти тағйирот + ҳамаи имкониятҳои мутахассис. |
| **Админи ноҳия** | «Мутахассис» | *Ихтиёрӣ, танҳо агар чанд мактаб бошад.* Барои як мактаб лозим нест. |

## Оғоз дар компютер
```bash
npm install
cp .env.example .env            # DATABASE_URL, DIRECT_URL, SCHOOL_NAME, SEED_DIRECTOR_PASSWORD
npx prisma migrate dev --name init
npm run db:harden               # муҳофизати AuditLog ва санҷишҳои база (CHECK)
npm run db:seed                 # мактаби №12 + ҳисоби мудир («mudir»)
npm test                        # санҷишҳои алгоритм
npm run dev                     # http://localhost:3000
```
Ҷойгиркунӣ дар интернет, бэкап ва гузариш ба VPS: **[docs/DEPLOY.md](docs/DEPLOY.md)**.

## Алгоритми чорякӣ (`src/lib/grades.ts`, `src/lib/periods.ts`)
- Чоряк аз рӯи санаҳое, ки мутахассис муқаррар кардааст.
- Баҳои чорякӣ = ҷамъ ÷ шумора → `roundGrade` (як функсия дар тамоми код): касри < 0.5 ба поён, ≥ 0.5 ба боло. 4, 6, 8, 9 → 6.75 → **7**.
- Баҳо нест → «бе баҳо» (тақсим ба сифр нест).
- Баҳои солона = миёнаи чорякҳо; вазни имтиҳон дар Танзимот (0% бо нобаёнӣ).
- Чоряки баста → баҳоҳо сабт (snapshot) мешаванд ва дигар тағйир намеёбанд; кушодан мумкин аст.

## Амният
- Логин + парол; паролҳо — танҳо хеши **bcrypt (cost 12)**. Паролҳои автоматӣ: 10 аломат аз CSPRNG.
- Воридшавии аввал → ивази ҳатмии парол (барои волид — аз рӯи танзими мактаб).
- Қуфл баъди N кӯшиши хато (танзимшаванда) + маҳдудият аз рӯи IP.
- Сессия: токени тасодуфӣ дар cookie `httpOnly`; дар база танҳо хеши SHA-256.
- **Сабти номи волид**: интихоби фарзанд танҳо дархост аст — бе тасдиқи мутахассис ягон маълумоти кӯдак нишон дода намешавад; дар рӯйхати оммавӣ ному насаби пурра нест; аз як IP то 5 сабти ном дар соат. Мактаб метавонад сабти номи мустақилро дар Танзимот хомӯш кунад.
- **RBAC дар сервер**: ҳар саҳифа `requireRole`, ҳар амал `assertRole` + санҷиши `school_id`; омӯзгор танҳо тақсимоти худ, волид танҳо фарзанди худ.
- `AuditLog` — танҳо INSERT (trigger UPDATE/DELETE/TRUNCATE-ро манъ мекунад). Ҳар амал сабт мешавад: воридшавӣ, баҳо, тасҳеҳ, парол, тақсимот, содирот ва ғ.
- Дар база: `CHECK` баҳо 1–10 ва «ғоиб → баҳо нест».
- HSTS, `noindex`, `robots.txt` — маълумоти кӯдакон дар Google намеафтад. Содироти CSV аз «formula injection» муҳофизат шудааст.

## Интернети суст ва сервери ройгон
- Саҳифаҳо дар сервер сохта мешаванд (JavaScript-и кам), шрифти системавӣ, бе китобхонаҳои калон.
- «Боргирӣ…» ҳангоми бедоршавии сервер (cold start).
- Ҳисоботҳо бо `groupBy` (дархостҳои кам), сабти тағйирот бо пагинатсия.
- Файлҳо (ҳуҷҷати сабабнок) дар база нигоҳ дошта намешаванд — дар Supabase Storage (ихтиёрӣ).
- Маълумот дар дастгоҳи корбар нигоҳ дошта намешавад (сабти офлайн нест).

## Содирот
- **Excel**: файлҳои CSV (Excel бевосита мекушояд) — журнал, чорякӣ, ҷамъбасти синф, ҳисобот, ҳамаи ҷадвалҳо.
- **PDF**: тугмаи «Чоп / PDF» дар ҳар ҳисобот → «Сохранить как PDF».

## Қоидаҳои қабулшуда (тағйирпазир)
- Одобу рафтор: намунавӣ / қаноатбахш / ғайриқаноатбахш.
- Баҳо барои рӯзи гузашта — танҳо тавассути «дархости тасҳеҳ».
- Агар ҷадвал барои синф пур шуда бошад, омӯзгор танҳо дар рӯзи дарси худ баҳо мегузорад; агар ҷадвал холӣ бошад — ҳар рӯзи чоряк.
- Омӯзгор метавонад дар ҳамон рӯз ҷойи холиро пур кунад (масалан аввал давомот, баъд баҳо), вале сабти мавҷударо иваз карда наметавонад.
- «Сабабнок»-и омӯзгор муваққатӣ аст; ҳуҷҷати мутахассис «нест»-ҳои давраро ба «сабабнок» иваз мекунад.
- Синфи 11 → «хатм»; дар гузариш синфҳо +1 мешаванд, ҷадвал аз нав сохта мешавад.
