# Калиди имзои APK

`release.jks` — калиди имзои барномаи «Журнали мактаб». **Онро нигоҳ доред ва нест накунед:**
бе ҳамин калид навсозии барнома дар телефонҳо насб намешавад (аввал бояд барномаи кӯҳнаро нест кард).

Калид дар ҳамин репозиторийи **private** нигоҳ дошта мешавад. Агар репозиторийро public кунед,
аввал ин папкаро нест кунед ва калидро ба GitHub Secrets гузаронед.
